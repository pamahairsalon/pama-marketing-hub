# PAMA Marketing Hub｜帕瑪行銷補給站

帕瑪造型沙龍門店行銷資源平台的前端 MVP。

## 本版功能
- 品牌首頁與快速導覽
- 素材卡片與分類篩選
- 關鍵字搜尋
- 文案一鍵複製
- 熱門話題靈感專區
- 行銷發布月曆示範
- 桌機與手機響應式版型

## 品牌識別
- PAMA Green：#375B57
- PAMA Gold：#DFB743
- Mist Blue：#8190B4
- Cream：#FFF6E9
- 品牌核心：Professional · Passion · Modern · Art
- 品牌成立：1989

## 預覽
此專案為純 HTML、CSS、JavaScript，無須安裝套件。部署至 GitHub Pages 或其他靜態網站服務即可預覽。

## 本版尚未包含
目前素材主視覺為 CSS 示意圖，素材下載尚未串接真實圖片檔；發布月曆是示範資料；管理入口目前為聯絡信箱連結，尚未實作登入、資料庫、媒體上傳或管理後台。

## 下一階段
1. 建立安全的管理者登入與角色權限。
2. 串接資料庫及雲端圖片／影片儲存。
3. 建立素材新增、編輯、下架與到期管理。
4. 建立可編輯的行銷月曆與公告管理。
5. 加入各門店聯絡資訊套版與素材使用統計。

安全提醒：不可將管理者密碼、API 金鑰或私密憑證提交到公開 repository。
