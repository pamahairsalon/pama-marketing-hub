# PAMA Marketing Hub｜設計師日常助手

這個網站主要提供帕瑪各門店設計師使用，協助設計師在日常工作中找到社群發文靈感，以及與顧客溝通、關懷時可參考的文字。

## 平台定位
**設計師不知道發什麼時，可以來這裡；不知道怎麼關心顧客時，也可以來這裡。**

## 本版功能
- 首頁兩大入口：我要發文、我要關心顧客
- 發文內容分類：作品分享、髮型知識、養護分享、日常限動
- 顧客關懷情境：服務後關心、居家照護、回訪邀約、日常問候
- 關鍵字搜尋
- 分類篩選
- 文案／訊息一鍵複製
- 話題靈感與使用提醒
- 桌機及手機響應式版型

## 使用原則
- 範例文字是參考，不應不經判斷直接套用。
- 請依照設計師與顧客的熟悉程度、實際服務內容調整語氣及細節。
- 顧客個人資料、對話紀錄及未經同意的照片，不應放到公開網站。
- 使用作品照片前，應先確認取得顧客同意。
- 髮況與居家照護建議應以實際評估及服務當日說明為準。

## 本版範圍
此版本是靜態前端網站，內容直接維護於 HTML 檔案。尚未包含登入、資料庫、管理者後台、門店個人化資訊或內容使用分析。
