# PAMA Marketing Hub｜設計師日常助手

這個網站主要提供帕瑪各門店設計師使用，協助設計師在日常工作中找到社群發文靈感、顧客關懷參考，以及簡單實用的工作小工具。

## 平台定位
**設計師不知道發什麼時，可以來這裡；不知道怎麼關心顧客時，也可以來這裡；需要快速製作圖卡時，也有工具可以協助。**

## 本版功能

### 社群與顧客關係
- 首頁兩大入口：我要發文、我要關心顧客
- 發文內容分類：作品分享、髮型知識、養護分享、日常限動
- 顧客關懷情境：服務後關心、居家照護、回訪邀約、日常問候
- 近期話題靈感雷達：髮色、髮型、年末造型趨勢，附貼文切角、限動互動、可複製文字與參考來源
- 關鍵字搜尋、分類篩選、文案一鍵複製

### 設計師小工具
- 休假表產生器：外部工具入口，連結為使用者提供的第三方網址
- 帕瑪小助手：連結至既有 ChatGPT 自訂 GPT，設計師登入自己的 ChatGPT 帳號後可開始對話（前提是建立者已開放適當分享權限）
- PAMA 快速圖卡排版器：在瀏覽器中製作社群圖卡
  - 可選擇作品分享、髮型知識、養護提醒、預約公告、節慶活動範本
  - 可製作 IG 貼文 4:5（1080 × 1350）或限時動態 9:16（1080 × 1920）
  - 可輸入主標題、副標題、補充說明及行動文字
  - 可選擇上傳自己的作品照片
  - 即時預覽、下載 PNG、複製搭配貼文文案
  - 上傳的照片僅在使用者瀏覽器本機處理，不會傳到 GitHub

## 使用原則
- 範例文字是參考，請依設計師與顧客的熟悉程度、實際服務內容調整語氣及細節。
- 作品照片、服務內容與髮況描述請以實際情況為準，並確認取得顧客同意。
- 顧客個人資料、對話紀錄及未經同意的照片，不應放到公開網站。
- 髮況與居家照護建議應以實際評估及服務當日說明為準。
- 話題區為編輯整理的趨勢觀察，不代表即時社群聲量排名；使用前請再次確認內容是否仍符合當期趨勢。

## 本版範圍與後續
此版本是靜態前端網站，內容直接維護於 HTML、CSS、JavaScript 檔案。尚未包含登入、資料庫、管理者後台、門店個人化資訊或內容使用分析。

後續可再建立總管理處專用的安全內容管理介面，讓總管理處能自行更新話題、文案、圖卡範本與外部小工具連結。
